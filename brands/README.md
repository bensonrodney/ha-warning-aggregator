# Brand assets

The icon/logo Home Assistant shows for this integration are **not** loaded from
this repository — Home Assistant serves them from
[`home-assistant/brands`](https://github.com/home-assistant/brands). The files
here are the source of truth; they have to be contributed to that repo for the
artwork to appear in the *Add integration* dialog and the Integrations page.

## Files

`custom_integrations/warning_aggregator/` mirrors the layout `home-assistant/brands`
expects:

| File | Size | Purpose |
| --- | --- | --- |
| `icon.png` / `icon@2x.png` | 256² / 512² | square mark (Integrations page, add dialog) |
| `logo.png` / `logo@2x.png` | ≤512 wide | full lockup, light UI |
| `dark_logo.png` / `dark_logo@2x.png` | ≤512 wide | full lockup, dark UI |

All are regenerated by [`generate_logo.py`](generate_logo.py):

```bash
uv run --no-project --with pillow brands/generate_logo.py
```

## Submitting to home-assistant/brands

1. Fork `home-assistant/brands`.
2. Copy this folder in:
   `cp -r brands/custom_integrations/warning_aggregator <brands>/custom_integrations/`
3. `python3 -m script.validate` (or `npm run validate`) in the brands repo, and
   run its image optimiser if it complains about file size.
4. Open the PR. Until it merges, Home Assistant falls back to a generic puzzle
   icon for the integration — everything still works.
