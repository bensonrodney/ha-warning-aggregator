# Blueprints

Automation blueprints for the Warning Aggregator integration. Import them from
the repo — they are **not** part of the HACS install.

| Blueprint | Import |
| --- | --- |
| `automation/warning_aggregator/on_problem.yaml` — run an action the moment a Warning Aggregator sensor leaves OK (and, optionally, another when it's OK again) | [![Import](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2Fbensonrodney%2Fha-warning-aggregator%2Fblob%2Fmain%2Fblueprints%2Fautomation%2Fwarning_aggregator%2Fon_problem.yaml) |
